# Доработанный бэкенд с настоящим распознаванием

Начните с **[DELIVERY.md](DELIVERY.md)** — что изменилось, что выбрано и почему, результаты.

- `backend/` — доработанный проект. Распознавание работает локально на открытых моделях,
  без платного API и без внешнего endpoint.
- `backend/RESULTS.md` — результаты на 25 фотографиях с явными знаменателями.
- `backend/docs/RECOGNITION.md` — проверенные проекты, лицензии, ограничения.
- `backend/docs/REFERENCE_GALLERY.md` — определение типа техники по эталонным фото:
  как добавить свои, что измерено, чего метод не умеет.
- `backend/demo_results/` — настоящие JSON/CSV, изображения с рамками, фрагменты номеров
  до и после исправления перспективы.
- `photos/` — исходные 25 фотографий без изменений.
- `assignment/` — исходное задание.
- `PROMPT_FOR_OPUS.md` — запрос, по которому выполнена работа.

Запуск:

```bash
cd backend
python scripts/init_config.py
docker compose up --build -d
```

Веса (~212 МБ) скачиваются при первом старте сервисом `fetch-models` и сверяются по
SHA-256. GPU не нужен: 2 ядра CPU и 2 ГБ RAM для worker.

Интерфейс проверки: **http://localhost:8000/ui/**, ключ — из `backend/.env`.

**Перед публикацией репозитория** прогоните `python backend/scripts/prepare_public_repo.py`:
в репозитории лежит рабочая съёмка и номера текстом.
