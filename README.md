# Scanagro / Fable

Backend для распознавания техники и государственных номеров на фотографиях.

- `backend/` — FastAPI, PostgreSQL, очередь заданий, локальные модели распознавания.
- `photos/` — 25 исходных фотографий для проверки.
- `assignment/` — исходное задание.
- `PROMPT_FOR_ASTRA6.md`, `PROMPT_FOR_OPUS.md` — контекст дальнейшей разработки.

Запуск: [backend/README.md](backend/README.md).
Проверенные изменения Astra: [backend/ASTRA6_REVIEW.md](backend/ASTRA6_REVIEW.md).

Это снимок текущей работы от 17.09.2026. Разработка продолжается, в том числе
параллельно в Opus. Отчёты относятся к указанным в них версиям и проверкам.
`demo_results/` содержит ранее полученные результаты Opus.

Секретный `.env`, виртуальные окружения, рабочая БД и кеши моделей не включены.
Модели загружает штатный `backend/scripts/fetch_models.py` с проверкой SHA-256.
Новый `.env` создаётся по инструкции бэкенда.
